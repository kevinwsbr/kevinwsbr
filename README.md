# Hi, I’m Kevin Lira

I’m a tech lead, engineer, and researcher working across web performance, usability, SEO, secure software engineering, and LLM-based vulnerability analysis.

I’m also a Ph.D. student in Computer Science at North Carolina State University, where my research focuses on how large language models can support automated software vulnerability detection and repair.

## What I Work On

- High-performance web platforms
- Front-end architecture and scalable user interfaces
- SEO, usability, and Core Web Vitals
- Automated testing and secure development workflows
- LLM security and software vulnerability repair
- Interprocedural code analysis across programming languages

## Research

My research studies practical methods for applying modern LLMs to real-world vulnerability analysis workflows, including production codebases, interprocedural context, multiple programming languages, and the cost of using LLMs for vulnerability detection and repair.
