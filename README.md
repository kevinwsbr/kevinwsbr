# Hi, I’m Kevin (z4ph0d)

I'm a tech lead, software engineer, and researcher specializing in web performance, SEO, software engineering, and LLM-based vulnerability analysis.

I'm also a Ph.D. student in Computer Science at North Carolina State University, where my research focuses on how large language models can improve automated software vulnerability detection and repair.

## What I Work On

- High-performance web platforms
- Front-end architecture and scalable user interfaces
- SEO, usability, and Core Web Vitals
- Automated testing and secure development workflows
- LLM-based vulnerability detection and repair
- Interprocedural code analysis across programming languages

## Research

My research explores practical approaches to applying modern LLMs to real-world vulnerability analysis workflows, including production codebases, interprocedural context, multiple programming languages, and the cost-effectiveness of LLM-based vulnerability detection and repair.
